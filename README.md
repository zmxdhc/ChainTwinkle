Converts log data from various sources into visual graphs and charts for network administrators and security analysts.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/ChainTwinkle.git`
2. `cd ChainTwinkle`
3. Install in editable mode: `pip install -e .`

## Configuration

ChainTwinkle is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
